# Лабораторна робота №4 - PyQt6 Profile Studio

Навчальний desktop-застосунок показує компонування віджетів, інтерактивну форму, меню QMainWindow, сигнали між власними компонентами, модальні та стандартні діалоги й QSS.

## Запуск

Потрібен Python 3.10+ та PyQt6. У корені проєкту:

```console
python -m pip install -r requirements.txt
python studio_app.py
```

Тема з `theme.qss` вмикається за замовчуванням. Щоб побачити базовий вигляд без QSS, запустіть `python studio_app.py --plain`.

## Керування

- **Файл**: відкрити або зберегти профіль JSON; `Ctrl+O`, `Ctrl+S`; `Ctrl+Q` завершує роботу.
- **Дії**: скинути форму, відкрити власний діалог профілю, швидко додати примітку, заблокувати сигнали.
- **Вигляд**: перемкнути QSS-тему.
- **Довідка**: інформація про застосунок і схему сигналів.

## Компоненти

- `ProfileEditor` містить форму, окрему валідацію, базові сигнали полів і числовий `scoreChanged`.
- `SummaryPanel` відображає профіль, індикатор, журнал і надсилає `annotationAdded`.
- `MainWindow` з'єднує компоненти зовні, формує меню, toolbar, статус-бар і відкриває діалоги.
- `ProfileDialog` повертає ім'я, групу та вік тільки після підтвердження.

## Матеріали звіту

- `report.pdf` - титульний аркуш, виконання 5 завдань, аналіз джерел та висновки.
- `ui_plain.png`, `ui_styled.png` - один і той самий інтерфейс до та після QSS.
- `ui_signals.png` - зміни, передані між компонентами сигналами.
- `ui_resized.png` - вікно після перевірки меншого розміру.
